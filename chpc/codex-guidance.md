# CHPC allocation discovery

For every CHPC allocation or job choice, run `mychpc batch` to get the full current list of account, partition, and QoS combinations. Use `chpc-allocs --quick` to inspect that inventory and `chpc-allocs --show-all REQUEST` to assess options for a job. Choose from the complete list before using `--best`. Treat saved account examples as illustrative; check every selected triple against the live list.
